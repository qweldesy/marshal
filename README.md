# Маршал — автосервис, Тольятти

Статический сайт автосервиса «Маршал» (Приморский бульвар, 55, Тольятти).
HTML/CSS/JS без сборки. Заголовки — Tektur, текст — Inter, телефоны — системным шрифтом.

## Источники контента

- Карточка организации на Яндекс Картах: https://yandex.ru/maps/org/marshal/74836494270/
  - рейтинг 5,0, 56 оценок, 42 отзыва, награда «Хорошее место 2026»;
  - режим работы пн–сб 09:00–19:00;
  - прайс «Товары и услуги» (обновлён 1 сентября);
  - особенности и виды работ;
  - фотографии из альбома (112 в карточке, 22 выгружено в альбоме).
- Телефон и мессенджеры — из задания: +7 (917) 158-20-02,
  https://t.me/marshal_sto, https://wa.me/79171582002.

Все цены, отзывы и фотографии взяты из карточки. Тексты отзывов приведены
фрагментами, без изменения смысла. Цены не являются публичной офертой.

## Структура

```
index.html          разметка, SEO, JSON-LD AutoRepair
css/style.css       дизайн-система и адаптив
js/main.js          меню, появление секций, счётчики, лайтбокс
js/motion.js        Motion 12 (локальная копия, UMD)
fonts/              Tektur + Inter (woff2, кириллица и латиница)
img/                фото из карточки, эмблема, карта, OG
```

## Локальный запуск

```bash
python3 -m http.server 8080
# http://localhost:8080
```
